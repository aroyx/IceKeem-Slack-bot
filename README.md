# IceKeem - A stupid slack bot

This repo hosts the life to the bot named "IceKeem", after Hackclub nuked "workflows" in our slack, my beloved bot IceKeem was shot dead in the carnage. After 6 months I got the time to work on it, and I did.
IceKeem is just as tasty as before. It does simple stupid things that it used to do earlier but this time with extra features!

Icekeem has 3 command now!

`/icekeem-help` to get help with using the bot
`/icekeem-ping` to check life of the bot
`/icekeem-blog` to fetch the latest bogus I published! (Highly recommend xD)

There may be bugs and I will fix them if I encounter them. Until then bye!
